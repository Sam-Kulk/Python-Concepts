- Loop statement is used to execute a set of statements repeatitavely in loop.
- while and for are the two types of loops

The for loop should be used to:
a. Iterate over a sequence(string,List,Tuple,Dictionary & set)
b. To execute a set of statements for the specific number of times in loop

The While loop should be used to:
To execute the set of statements in a loop until the condition is true.
